# Dumbo

An iOS app for managing app access and notification distractions through reusable app lists and iOS Focus integration. Dumbo is a working name taken from the project folder.

This project uses OpenSpec. Requirements and platform research are in [docs/product-brief.md](docs/product-brief.md). Implementation has not started; Xcode is currently being installed.

## Development

Use the installed OpenSpec Codex skills to propose changes, implement them, and verify them. Start with a physical-device feasibility prototype before building the full interface.
